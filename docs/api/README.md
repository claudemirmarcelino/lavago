# Contratos de API

Serão definidos após a modelagem inicial. Ainda não existem endpoints de negócio.

Contratos futuros devem especificar autenticação, autorização, entrada validada,
resposta, erros, chave de idempotência e identificador de correlação. Realtime será
usado para atualizar a interface quando necessário, sem substituir o estado
persistido no banco nem servir como fila de comandos de automação.
